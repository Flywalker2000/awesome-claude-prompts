# Instagram Bot

This project is an Instagram bot for automating interactions.

## Setup

1.  **Clone the repository (if you haven't already):**
    ```bash
    # git clone <repository_url>
    # cd <repository_directory>/instagram_bot
    ```

2.  **Create a virtual environment (recommended):**
    ```bash
    python -m venv venv
    source venv/bin/activate  # On Windows use `venv\\Scripts\\activate`
    ```

3.  **Install dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

4.  **Configure the bot:**
    *   Update `bot.py` with your Instagram credentials and desired settings.

## Running the Bot
```bash
python bot.py
```
